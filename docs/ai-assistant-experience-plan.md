# AI 助手体验改造方案导读

完整、可交给 agents 执行的策划已整理到项目根目录：

**[AI_ASSISTANT_EXPERIENCE_PLAN.md](../AI_ASSISTANT_EXPERIENCE_PLAN.md)**

以根目录主文档 v2.1 为唯一执行依据，本文保留为入口，避免两个版本的产品规则和容量计算相互冲突。

本期目标：

- 采用 ChatGPT 网页式布局：历史侧栏/抽屉、居中消息、底部输入框。
- 服务器保存多会话，查看账单、返回、刷新、重新登录和换设备均能恢复已发送历史。
- 每条 AI 回复支持原始 Markdown 复制，代码块可独立复制，提供真实成功/失败反馈。
- 补齐草稿、滚动锚点、断线确认、失败重试、停止生成、重新生成、版本与编辑分支。
- 区分完整历史、当前会话摘要和长期记忆；记忆可查看、更正、关闭和忘记，财务金额实时查账。
- 默认每段会话 2 MiB 或 200 次用户提问、每次提问/回答尝试 64 KiB、每用户总量 100 MiB；具体计量、版本、预留和续聊规则以主文档为准。

主文档包含 13 个实施任务、依赖关系、40 项验收要求、接口与数据契约、两端产品流程、三库/真实模型验证和迁移回滚要求。第二轮补齐了清空后迟到请求、刷新后的发送确认、多设备同步、生成中的记忆撤销、浏览器缓存、分支中途失败与具体视觉验收标准。

实现及隔离环境验证见 [逐项验收记录](ai-assistant-experience-verification.md)，界面证据见 [独立 UI 审查](ai-assistant-ui-review.md)。已实现不等于全部验收通过；真实主备模型、可靠手机设备及读屏等尚未完成的门槛，以验收记录为准。旧方案的基线测试不替代本方案验收。
