# AI 助手界面与查询修复（2026-10-16）

参考提供的 `ai_assistant_redesign.html` 原型，桌面与移动端共用奶油白背景、薄荷绿、轻量卡片和圆角触控按钮。消息复制（包括原始 Markdown 和代码）、重新生成、编辑、分支、历史管理及发送/停止使用带可访问名称的图标。复制反馈、面板、提示和确认弹层提供过渡，并支持减少动态效果。

## 操作范围

- 工具栏仅保留会话历史、新建及标题；移除更多菜单、导出、全部清空与长期记忆管理入口。
- 历史继续从服务器读取，支持单条确认删除；修复删除非当前会话后列表不刷新的问题。后台记忆机制与已有 API/数据不删除、不迁移。
- 历史动画在账号或删除纪元变化时立即卸载旧内容，避免上一账号标题在退出动画中残留。
- 消息入场只改变透明度，不改变阅读锚点坐标；前进/后退、加载旧消息和流式增长保持阅读位置。
- 重复提交或等待送达确认不再误报为“正在生成”；功能不可用与实际生成中的状态分开处理。
- 同一会话刷新不再用旧的已保存草稿覆盖新输入，首次加载仍正常恢复已保存草稿；回归验证实际发送内容与最新输入一致。

## 查询修复

普通多工具查询在原 16,000 输入预算下可复现 `context_budget` 中断。压缩重复的系统提示和工具说明后，五次实际 SQLite 工具调用通过 HTTP 适配器完成，预算及参数校验不变。没有截断匹配账本范围、丢弃金额精度或把失败解释为空数据。明确了交易 keyword 搜索备注、账户/分类名称应先解析为 ID 的区别。

详见 [harness 验证记录](ai-assistant-harness-verification.md) 的 2026-10-16 补充说明。

## 验证

- `npm run lint`：通过（行数检查、Vue/TypeScript、ESLint）。
- `npm run test`：47 个文件、38,927 项通过（包含草稿刷新、删除历史和发送状态回归）。
- `npm run test:browser`：7 个文件、64 项 Chromium 测试通过；新增身份首帧检查亦通过。
- `node scripts/assistant-experience-e2e.mjs`：40 个桌面／移动端场景通过，26 次确定性模型协议调用。覆盖原始 Markdown 剪贴板、阅读位置、草稿刷新、多标签冲突、账号切换首帧、断线恢复、发送去重、失败重试、分支和单条删除；结果保存在 `.vitest/assistant-e2e/results.json`。
- `npm run build`：通过。
- `go vet ./...`、API/services 测试、`BUILD_PIPELINE=1 go test ./...`：通过。CI 模式跳过外部在线接口，不代表这些接口已验证。
- 普通 `go test ./...`：白俄罗斯、乌克兰两项在线汇率接口测试因网络或第三方响应失败；助手相关包通过。
- 真实桌面（1440px）/移动（390px）路由：独立临时 SQLite 账本、真实 API、确定性模型协议服务；检查欢迎页、提问回答、历史、取消删除、暗色模式、无横向溢出和图标名称/44px 目标，页面脚本错误为零。截图位于 `.vitest/redesign/`。

移动端 E2E 显式等待历史抽屉退出动画完成后再填输入框。最小复现证明动画期间原生模态框仍使背景输入框不可交互；自动填充未触发输入事件，不能作为有效用户输入。修正仅同步真实可交互状态，保留所有内容、阅读坐标及账号隔离断言。

同时恢复了工作区漏带的五个分类图标模块，236 个图标映射与拆分前 Git 版本一致；修正 `.gitignore` 的 macOS `Icon` 规则误排除。依赖清单与锁文件不变。
