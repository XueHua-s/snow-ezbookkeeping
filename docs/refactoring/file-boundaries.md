# 单文件职责拆分

验收：项目源码、测试和样式每文件最多 500 行，包含注释与空行。检查项目根目录及 `src/`、`pkg/`、`cmd/`、`scripts/`，排除第三方依赖、构建产物、技能包和非代码数据文件。保留现有公开导入入口、HTTP 合约和存储结构。

## 设计原则

以业务知识划分模块，避免按执行先后机械切块。Go 保持原 package 和事务边界；TypeScript 保留兼容导出入口，内部直接依赖职责模块。响应式状态只有一份，计算结果由 computed 派生，状态和操作通过有类型的窄接口连接。

## Vue 职责边界

| 页面或组件 | 职责边界 | 数据流 |
| --- | --- | --- |
| 交易列表 | 页面编排、筛选、列表/日历展示、批量操作 | 筛选值下传，选择与操作事件上报 |
| 交易编辑 | 页面编排、金额及账户输入、分类标签、附件和保存 | 输入使用明确的双向模型，保存由页面负责 |
| 导入检查 | 筛选和选择、预览表格、批量修复、导入导出 | 预览数据下传，修复/选择动作交给状态模块 |
| 账户/分类/标签 | 页面加载、列表条目、编辑及管理操作 | 条目只接收显示数据和操作事件 |
| 统计/探索 | 查询配置、图表配置、结果展示 | 查询及图表状态集中维护，图表只负责渲染和选择 |
| 用户与偏好设置 | 按设置主题划分独立表单区域 | 设置值和修改事件明确传递 |
| 图表组件 | 图表数据转换、选项构建、交互与导出 | 渲染组件持有实例，计算模块隐藏图表库细节 |

## 验证

改动前：前端 lint、17 个测试文件（38,719 项断言测试）通过。Go 全量测试中的白俄罗斯国家银行汇率在线请求失败；须单独报告此基线问题，不能计为重构回归或全量通过。

每批执行类型检查和对应测试，最终执行行数检查、Go 测试/vet、前端 lint/test/build，并检查模块运行时循环依赖。

## 拆分结果与持续检查

原有超限的 90 个运行源码文件已按领域职责拆分；另外 19 个 Go 测试文件和 2 个样式文件也完成拆分。Go 测试保留测试名称和断言，按输入解析、字段、时区、取消等主题组织；样式保留选择器和加载顺序。

运行 `npm run check:source-lines` 检查全部项目代码。检查按物理行计数，包含注释与空行，超出 500 行时返回非零状态。当前检查 1,527 个源码、测试和样式文件，超限数量为 0。

Vue 页面保留路由与生命周期编排；筛选菜单、表单区域、列表条目与设置区块各自承担独立职责。菜单的模板引用由实际渲染菜单的组件持有；金额草稿只在菜单打开时从当前查询恢复。新增回归测试覆盖这些行为。插槽数据通过可写字段绑定，避免对插槽局部变量赋值。

设计自评：8/10。领域模块、兼容入口、事务边界及响应式状态所有权已明确；部分历史页面仍有较宽的编排接口。进一步达到 10/10，需要结合后续功能演进收窄这些接口，并增加交易编辑、导入检查等真实浏览器交互覆盖；不应为了减少接口字段而隐藏依赖或破坏现有合约。

## 生产分包回归补充

真实 Docker 生产产物启动验证发现：原分包规则只匹配 `locales/helpers.ts`，拆分后的 `locales/helpers/` 被分入语言资源包，与应用公共包产生初始化循环。该问题无法由开发服务器模式的组件测试或“构建成功”发现。已将国际化辅助模块和拆出的公共库模块保留在原公共分包中。

新增 `EBK_SMOKE_BASE_URL=http://127.0.0.1:<port> npm run test:production`：直接访问运行中的生产产物，确认桌面/移动登录表单实际可见，且没有浏览器运行时错误或失败请求。TLS 测试环境可显式设置 `EBK_SMOKE_IGNORE_TLS_ERRORS=true`。应先对隔离候选容器执行此检查，再切换公开入口；只检查 HTTP 200 不足以判定 SPA 可用。修复后隔离 Docker 的两个入口均通过。代码行数检查现覆盖 1,528 个文件，仍无超限。
